# Notas — Tarea 01 (Persistencia, API REST y Autenticación)

Proyecto de Línea de Énfasis II — Uniremington.

App de gestión de notas hecha 100% en Python:
- **notas-api/**: backend Flask + SQLAlchemy + JWT (API REST).
- **notas_app/**: app móvil en Flet, con persistencia local en SQLite y modo offline.

## Cómo correr el backend
```bash
cd notas-api
venv\Scripts\activate
python app.py
```

## Cómo correr la app
```bash
cd notas_app
venv\Scripts\activate
python main.py
```
